## Day 1 tasks (in order)

1. `agents/tools/math.ts` and `agents/tools/store.ts`: typed wrappers around `/math` and the Store that also emit `tool_call` events.
2. `agents/orchestrator.ts`: the 7 step protocol in plain code, `AGENTS_MODE` switch (`scripted` | `live`, auto = live when any key exists), `AGENT_EVENT_DELAY_MS` pacing, persistence with `store.addEvent`, `AGENTS_FALLBACK` replay of `/agents/fallbacks` on failure.
3. Scripted mode end to end first: `POST /api/plan/generate` -> run -> `GET /api/agents/stream` SSE -> `GET /api/agents/runs/[runId]`. The Frontend Agent Room needs this on day 1.
4. Doctor (live) with `buildConstraints` + narration; Chef candidate generation mapped to `foodId`s; Budget pricing and swaps; the negotiation loop with real `optimizePlan` calls.
5. Vision A + B and the voting formula in `POST /api/log/photo`; Monitor in `POST /api/monitor/run` and after readings; Coach in `POST /api/coach` with tool access to the current plan and targets.
6. `agents/evals/run-evals.ts` (`npm run evals`) and `agents/evals/replay.ts`.

## Definition of done

- Scripted mode produces a full negotiation with no API keys: 15 to 25 events, >= 1 objection and concession, all under 140 chars, plan saved and `verifyPlan` clean.
- Live mode produces the same event shapes with real models; any failure falls back to scripted or the saved replay without the UI noticing.
- Doctor constraints are byte identical at the start and end of every run.
- `npm run evals` passes; every new function has a Vitest test under `agents/**/*.test.ts`.
- Vision voting returns `agreement` and at most one question; Monitor replans at most once a day and raises urgent alerts for danger readings.

## How to run and test

```
npm run dev
curl -s -X POST localhost:3000/api/auth/login -H "Content-Type: application/json" -d "{\"identifier\":\"alex\"}" -c c.txt
curl -s -b c.txt -X POST localhost:3000/api/plan/generate -H "Content-Type: application/json" -d "{\"trigger\":\"manual\"}"
curl -N -b c.txt "localhost:3000/api/agents/stream?runId=<runId>"
npm test -- agents
npm run evals
```

PowerShell users: `Invoke-WebRequest` works too, or use the `/replay alex` command in Claude Code. Force offline: `AGENTS_MODE=scripted`.

## Never touch

`/types/contracts.ts`, `/math/**` (ask Math for a new signature), `/lib/db/**` (ask Backend for a Store method), `/app/(app)`, `/components`, `/mocks`. Do not change numbers in `guidelines.json` without a cited source and the Lead's ok.

## Requesting a contract change

Group chat: "Contract request: <type>.<field> because <agent needs it>". Common needs are already covered: `AgentEvent.data` is a free `Record<string, unknown>` for tool payloads, `MealPlan.bestEffort` marks concessions, `MonitorResult.tdee` carries the posterior.
